# Security policy

## Reporting a vulnerability

Report a suspected vulnerability privately: [report it here](https://github.com/pterw/eulerase/security/advisories/new), or open the repository's Security tab and choose "Report a vulnerability".

Do not open a public issue for it. Issues are public.

## What to include

- The version: run `python -c "import eulerase; print(eulerase.__version__)"` and paste the line it prints.
- The command you ran or the input you gave.
- What happened, and what you expected.

Leave out anything private, such as sequences you do not want published. Describe them instead.

## Supported versions

Fixes go into the latest release.
